# .github

Organization-wide files for Better Than Medallion:

- `profile/README.md`: the public organization profile.
- `brand/`: the brand kit (logo, avatar, banners, palette and typography in `brand/BRAND.md`).
- `CONTRIBUTING.md`, `SECURITY.md`, and the issue and pull request templates in `.github/`: defaults used by every repository of the organization that has no file of its own.

This repository is public, so keep anything about strategies, positions, venues, keys or results out of it. Internal material lives in `.github-private`.
